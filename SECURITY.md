# Security policy

## Reporting a vulnerability

Do not open a public issue for a security problem.

Report it privately in one of these ways:

- GitHub private vulnerability reporting: the "Report a vulnerability" button on this repository's Security tab.
- Email: info@andaphilosophy.com.

Describe the problem, the affected URL or file, and the steps to reproduce it. We reply as soon as we can and tell you when it is fixed.

## Scope

This repository and the site it deploys: andaphilosophy.com, www.andaphilosophy.com and andaism.com. The site's `/.well-known/security.txt` names the same contact.

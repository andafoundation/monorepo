# Skill routing

Before you implement, load the skill of every row that matches the task. Load nothing that does not match. Skip loading for text, styling and rename edits and for reading code.

| Task context | Skill |
|---|---|
| A try/catch, a promise rejection handler or another error path | `no-silent-failures` |
| A code comment or docblock | `code-comments` |
| Pages, layouts, the `app/` directory, route handlers, metadata, images, fonts, data fetching in `projects/website/` | `next-best-practices` |
